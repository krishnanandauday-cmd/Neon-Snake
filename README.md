# Neon-Snake
A neon-themed Sanke game developed using Python and Pygame.

About the Project

NEON SNAKE is a Windows desktop game inspired by the classic Snake game. Players control a snake, collect food, earn points and progress through different levels while avoiding collisions.

Features

- Modern neon cyberpunk interface
- Three difficulty levels: Easy, Normal and Hard
- Keyboard controls using Arrow Keys and WASD
- Score tracking and level progression
- Increasing game speed
- Pause and resume functionality
- High-score tracking and storage
- Animated food and visual effects
- Game Over and Victory screens

Technologies Used

- Python – Main programming language
- Pygame – Game development library
- JSON – High-score and game-history storage
- OpenCode – AI-assisted development
- PyInstaller – Executable packaging
- Inno Setup – Windows installer creation


Project Structure

File| Description
"main.py"| Main game source code
"neon_snake.ico"| Application icon
"NeonSnake.spec"| PyInstaller configuration
"NeonSnake.iss"| Inno Setup installer script

Running the Project

1. Install Python on your computer.

2. Install Pygame using:
   
   "pip install pygame"

3. Run the application using:
   
   "python main.py"

Application Packaging

The Python application is packaged into a standalone Windows executable using PyInstaller. Inno Setup is used to create an installable Windows application.

Project Objective

To develop an interactive desktop game while demonstrating Python programming, game development, data management and application packaging.
